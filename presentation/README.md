# Presentation

`AcousticSense_Anomaly_Detection.pptx` is the final 13-slide deck, **generated by `build.js`, not drawn by hand**. The earlier 34-slide version is kept as `AcousticSense_Anomaly_Detection_34slides.pptx` (built by `build_34.js`) in case a longer talk is needed.

## Files

| File | Purpose |
|---|---|
| `prep_data.py` | Turns a notebook's exported CSVs into `data/<tag>.json` (metrics, confusion matrices, mean ROC, loss curves, score histogram). |
| `make_params.py` | Counts the parameters of the four models and writes `data/params.json`. |
| `build.js` | Builds the 13-slide deck (pptxgenjs). Needs `data/dense.json`, `cae.json`, `ast.json`, `sup.json` and `params.json`. |
| `build_34.js` | Builds the older 34-slide deck. Models without data become blank "RESULTS PENDING" slides. |
| `qa.py` | Checks that text fits its box and nothing leaves the slide. No renderer needed. |
| `assets/` | Images used on the slides (spectrograms from the Kaggle dense run, a t-SNE of AST embeddings of fan ID 02, an ROC figure). |

`data/` is gitignored, so regenerate it before building.

## Rebuild

```bash
# from the project root
.venv/bin/python presentation/make_params.py
.venv/bin/python presentation/prep_data.py dense export_dense --split blocked
.venv/bin/python presentation/prep_data.py cae   export_cae   --split random
.venv/bin/python presentation/prep_data.py sup   export_sup   --split "blocked*"
.venv/bin/python presentation/prep_data.py ast   ~/Downloads/results/embedd --split random-quick

cd presentation && npm install
NODE_PATH=$PWD/node_modules node build.js
../.venv/bin/python qa.py AcousticSense_Anomaly_Detection.pptx
```

`--split` sets the tag shown on every results slide: `blocked` (strict), `random` (not strict), `random-quick` (the AST quick run) or `blocked*` (the supervised split is the notebook default, but the export does not record it).

The AST export is **not in the repository**. The deck uses the quick run (IDs 00 and 02, at most 150 clips per class), downloaded from Kaggle.

## Checking the deck

The deck cannot be rendered on the development machine (LibreOffice has no Impress component), so `qa.py` checks geometry only. Open the file in PowerPoint to review it.
